# AppIcon — Draft Samples

Temporary draft samples for choosing the SeekZip app icon direction.
These are **not** the final macOS iconset — the proper iconset (squircle,
all required sizes, light/dark) will be made later after a concept is approved.

## Samples

- `X3-dark-icon.png` — Dark icon candidate, reserved for later. 3D blue Finder-style folder, teal eyes glancing right, subtle smirk, teal zipper, colourful files flying out, on a deep navy background.
- `Y1-light-white-shine.png` — Light icon candidate. Same folder as X3, on a bright white background with a diagonal mirror light shine.
- `Y2-light-lavender.png` — Light icon candidate. Same folder as X3, on a soft light lavender background with a glow behind the folder.
